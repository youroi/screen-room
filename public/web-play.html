Player setup

In Via, install the player script once. Then open the player while connected to Wi-Fi that can reach Circle.

Install Via script

For browsers without Via scripts, use a bookmark.

  1. Bookmark this page. Edit the bookmark, name it Still Player, and replace its URL with the one below.
  2. Open the Circle tab. It will display a short server response.
  3. In that tab, type Still Player into the address bar and tap the bookmark suggestion.
