Circle web player

In Via, install the player script once, then open the Circle tab. Play handles Dolby Digital audio automatically.

Install Via script

For browsers without Via scripts, use a bookmark.

  1. Bookmark this page. Edit the bookmark, name it Drisho Player, and replace its URL with the one below.
  2. Open the Circle tab. It will display a short server response.
  3. In that tab, type Drisho Player into the address bar and tap the bookmark suggestion.
